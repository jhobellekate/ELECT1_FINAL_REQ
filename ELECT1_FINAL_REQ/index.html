Types of Credentials

Not all credentials are the same. Here is the difference between the three types you will see in this directory.

🏅

Certification

Validates your skills through a defined certification process, such as passing an exam.

Sample Certifications

  • CompTIA Network+
  • CompTIA Security+
  • Cisco Certified Network Associate (CCNA)
  • Cloud Digital Leader
  • Certified in Cybersecurity (CC)
📜

Course Certificate

Shows that you completed a specific course or program.

Sample Courses

  • Google IT Support Certificate
  • Google Cybersecurity Certificate
  • Google Data Analytics Certificate
  • CS50x: Introduction to Computer Science
  • Responsive Web Design
🎖️

Digital Badge

A digital recognition of an achievement or skill that you can show online.

Where to Get Digital Badges

  • Cisco Networking Academy (Skills for All)
  • Google Cloud Skills Boost
  • AWS Skill Builder
  • IBM SkillsBuild
  • Credly (a platform used by many providers)

About CPE Learning Hub

Purpose

CPE Learning Hub is a curated directory that helps students discover learning opportunities and understand the difference between earning a professional certification and completing a course.

Target Audience

  • Computer Engineering students
  • Students beginning their IT and networking journey
  • Learners looking for relevant certifications and courses
  • Students who want to build skills outside their curriculum

Scope

This website does:

  • Organize resources by credential type and category
  • Show information about each resource
  • Link to official provider pages

This website does not:

  • Issue certifications or host courses
  • Process payments or track progress
  • Include every certification in the world
